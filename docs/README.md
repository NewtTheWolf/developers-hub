# TurboSMTP Documentation

Topic guides for integrating with the TurboSMTP API. Start with **Getting Started** for authentication and your first send, then dive into the area you need.

| Guide | Description |
|---|---|
| [Getting Started](getting-started.md) | Authentication, API Keys, Consumer Keys, base URLs, and your first send |
| [Transactional Email](transactional.md) | Send email via `/mail/send` — attachments, embedded images, custom headers |
| [Analytics](analytics.md) | Per-message delivery events, status lifecycle, and CSV export |
| [Suppressions](suppressions.md) | Query, import, export, and delete suppressed addresses |
| [Email Validation](validation.md) | Real-time single-address validation and bulk list workflows |
| [Webhooks](webhooks.md) | Real-time delivery and engagement event payloads |
| [Account Management](account.md) | Consumer keys, passwords, usage alerts, credits, reference data |
| [Subaccounts](subaccounts.md) | Multi-tenant client management for agency plans |

For the OpenAPI specification and interactive reference, see [API Reference](../api-reference/README.md). For client libraries, see [SDKs](../sdks/index.md).
