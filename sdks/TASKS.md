## Fixed decisions (see `plan.md`)
- Tooling: **OpenAPI Generator** (free/OSS) + curated facade. Kiota is a free per-language fallback.
- Development home: everything under `developers-hub/sdks/` — one repo anyone commits to.
- Publish topology (decided 2026-08-05, **[ADR-0003](docs/adr/0003-sdk-repository-topology.md)**): five CI-generated **read-only mirror repos** (`turbosmtp-node`/`-python`/`-dotnet`/`-go`/`-php`). Forced by public Packagist (no subdirectory `composer.json` outside the paid tier) and Go (subdirectory modules bake the repo path into the import path + need prefixed tags). Rejected full polyrepo: it costs 6 PRs / 5 CI runs per spec change and no single run would see all five facades. Recorded as **[ADR-0003](docs/adr/0003-sdk-repository-topology.md)**; implemented by 4.7.
- Versioning: **independent per language** — no lockstep family version. Tags are `<lang>/vX.Y.Z` here, translated to unprefixed `vX.Y.Z` on each mirror.
- Build toolchains (**[ADR-0004](docs/adr/0004-build-toolchain-version-policy.md)**): pin patch-only (`~`, never `^`) at the exact validated version; each package declares a minimum supported *consumer* toolchain, and every compiler bump is gated on the consumer-floor check (build → pack the real artifact → install into a scratch consumer → exercise every documented consumption path at the floor). Applies to all five languages — read before setting up 3.1/3.4/3.7/3.10.
- Packaging: **one unified package per language**; domains are namespaces (`mail`, `validation`, …). Re-derived from each ecosystem's own official guidance and ratified 2026-08-14 as **[ADR-0007](docs/adr/0007-sdk-packaging-granularity.md)**, which carries the primary-source evidence inline. Comes with three refinements: modular *consumption* not modular *release* (Node-only subpath exports, never before P1, root export stays complete); a carve-out for webhook signature verification (not an API domain); and **four recorded flip triggers**, one of which is "the org sanctions `turboSMTP-js`" → **Node alone** would diverge. Also fixes finding **E4** in `client-contract.md` §2: Layer 1 hiding is enforceable only in Node/Go, convention-only in Python/PHP, and **impossible in C#**.
- Rollout: priority-driven — **P0 Mail → P1 Validation → P2 → P3(maybe never)** — with a scope decision between tiers.
- Language order after the Node reference (decided 2026-08-14): **Python first**, with its registry publish (3.3b) deliberately last and left blocked. Python development is fully unblocked because the PyPI name conflict touches only the *distribution* name, never the import name. Consequence: **9.7 lost its runway and is now time-critical** — see the Phase 3 preamble.
- Program authority (decided 2026-08-11, **[ADR-0005](docs/adr/0005-sdk-program-authority.md)**): `developers-hub/sdks/` is **the** SDK decision record. The parallel RFC track in the private `turboSMTP/developer-ecosystem` repo is superseded for SDK matters and will be deprecated. `turboSMTP-js` / the `@turbosmtp` npm scope are **out of scope** — 2.5 stays blocked.
- Legacy SDKs (decided 2026-08-11, **[ADR-0006](docs/adr/0006-legacy-official-sdk-consolidation.md)**): `turboSMTP-csharp`/`-php`/`-python` are **superseded, not modernized**, and deprecated per language as each replacement publishes. Their SwaggerHub spec source is retired. ⚠️ The legacy `turboSMTP-python`/`turboSMTP-php` **occupy two mirror names** (GitHub names are case-insensitive-unique) — rename before creating those mirrors; archiving does not free a name.
- Registry occupancy (verified 2026-08-11, re-verified before use): **PyPI `turbosmtp` is TAKEN** by an abandoned 2015 third-party package → needs a §6 amendment (see 3.3). Free: NuGet `TurboSMTP`, Packagist vendor `turbosmtp`, `github.com/turbosmtp/turbosmtp-go`. npm `@turbosmtp/sdk` blocked (2.5).
