# TurboSMTP SDKs — Roadmap & Tasks

Scoped task list for the SDK effort. Strategy and rationale live in [`plan.md`](./plan.md); this file
is the executable checklist. It **refines and replaces Phase 3** ("SDK Modernization") of the
repo-level [`../TASKS.md`](../TASKS.md) — reconcile that file's 3.1–3.20 into this when adopted.

## Statuses
`DONE` `REVIEW` `WIP` `PENDING` `PAUSED` `BLOCKED`

## ADRs column
Numbers refer to the decision records in [`docs/adr/`](docs/adr/README.md) — the ADRs that decide,
gate or constrain that task. They hold the rationale; this file holds the outcomes.

## Fixed decisions
Strategy and rationale live in [`plan.md`](./plan.md) (fixed decisions 1–6) and the ADR series —
see the [index](docs/adr/README.md). Not restated here. What this file owns:

- **Rollout order:** priority-driven — **P0 Mail → P1 Validation → P2 → P3 (maybe never)** — with
  a scope decision between tiers.
- **Language order after the Node reference: Python first.** Its registry publish (3.3b) is
  deliberately last and stays blocked; all other Python work is unblocked, because the PyPI
  conflict touches only the *distribution* name, never the import name. Consequence: **9.7 is now
  time-critical** — see the Phase 3 preamble.
- **Registry occupancy** (re-verify before use): PyPI `turbosmtp` **taken** (3.3b), npm
  `@turbosmtp/sdk` **blocked** (2.5). Free: NuGet `TurboSMTP`, Packagist vendor `turbosmtp`,
  `github.com/turbosmtp/turbosmtp-go`.
